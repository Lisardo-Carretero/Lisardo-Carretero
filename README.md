## 🚀 Proyecto destacado

## **TypeScript Dashboard (IoT)**
🔗 **Repositorio:** [Lisardo-Carretero/typescriptdashboard](https://github.com/Lisardo-Carretero/typescriptdashboard)  
🧾 **Descripción:** _IoT dashboard using Typescript and PostgreSQL._

Este proyecto representa muy bien mi forma de trabajar: convertir datos en tiempo real en una interfaz clara, útil y accionable.

### ¿Qué demuestra este proyecto?
- Diseño de una solución de extremo a extremo para visualización IoT.
- Dominio de **TypeScript** como lenguaje principal del proyecto.
- Integración con **PostgreSQL** para persistencia y consulta de datos.
- Enfoque en claridad, estructura y evolución del producto.

### Stack principal
- **TypeScript** (98.7%)
- **PostgreSQL**
- Arquitectura orientada a dashboards y monitoreo

Aprovechando al máximo los recursos que pueden ofrecer ciertos servicios gratuitos.
La necesidad de este proyecto partió de una asigantura del master que ha ido creciendo y abrazando nuevas funcionalidades con forme iban haciendome falta.
